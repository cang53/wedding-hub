# Handoff: Apple-style redesign of Wedding Hub Target repo: `cang53/wedding-hub` (Next.js App Router + Tailwind + Supabase), branch `main`. ## Overview Wedding Hub is currently a cream/burgundy/gold "editorial" app: a serif display face, a large `Celal & Selver` masthead, a pill tab row, and heavy use of emoji and coloured badges. This handoff replaces that visual language with an Apple-style system — SF typography, inset grouped lists, hairline separators, near-monochrome surfaces, and colour used only where it carries meaning. Scope of the redesign: **five screens** — Overview (`/dashboard`), Life after (`/life-budget`), Honeymoon (`/honeymoon`), Guests (`/guests`), The day (`/wedding-day`). To-Do, Agenda and Apartments are out of scope but should adopt the same tokens and list patterns. **No behaviour changes are requested.** Every server action, Supabase query, realtime channel and dialog keeps working exactly as it does today. This is a presentation-layer change. ## About the design files `Wedding Hub - Apple v2.dc.html` in this bundle is a **design reference written as a single self-contained HTML prototype** (plus its `support.js` runtime). Open it in a browser to see the intended look and behaviour. It is **not production code to copy**: it uses inline styles, a custom template runtime, and hard-coded sample data. Your task is to **recreate this design inside the existing Next.js + Tailwind codebase**, using its established patterns: server components for data, `"use client"` clients for interaction, `src/components/ui/*` primitives, and `src/app/globals.css` for tokens. Port the *visual system and layout*, not the file. `Wedding Hub - Apple.dc.html` (v1) also exists in the project but is superseded — ignore it. ## Fidelity **High-fidelity.** Colours, type sizes, weights, letter-spacing, radii and spacing in this document are final.
